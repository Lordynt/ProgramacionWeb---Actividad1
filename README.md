# ProgramacionWeb - Actividad 1

Repositorio con los ejercicios de la **Actividad 1**, desarrollados como parte de la materia de Programación Web.

## Descripción de la actividad

Esta actividad sirve para comprender los conceptos fundamentales del desarrollo web front-end mediante ejercicios sencillos.

Los ejercicios permitieron comprender como:

- Hacer la estructura básica de un archivo HTML.
- Uso de las diferentes etiquetas de HTML.
- Uso de enlaces internos y externos.
- Uso de imágenes con rutas relativas.
- Creación de listas ordenadas y desordenadas.
- Construcción de tablas con celdas combinadas.
- Formularios con validación HTML5 y estilos CSS y JavaScript.

## Tecnologías utilizadas

- **HTML5** — Estructura y contenido.
- **CSS** — Estilos, diseño y maquetación.
- **JavaScript** — Interactividad y lógica.
